This [repository](https://github.com/cahaj/uni/) contains my university-related stuff like projects and notes. It is currently being hosted on Github Pages as a directory browser using Github Actions. Markdown files in the repository are pre-rendered on build. README.md files, like this one, are always rendered after the directory browser. All other text-based files, like code, are rendered with client-side JavaScript into a pre-rendered skeleton containing basic information about the file. Binary files are downloaded instead.
